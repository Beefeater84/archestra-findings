# Archestra field notes

Hands-on evaluation of [Archestra](https://archestra.ai) 1.4.0-rc.27 (quickstart, Docker Desktop on Windows 11), September 30 – October 2, 2026.

- **Dashboard:** `index.html` (served via GitHub Pages)
- **Machine-readable findings:** `findings.json`

Each finding is a testable hypothesis with status, severity, steps, expected and actual result, and a contribution idea. Site names, accounts, keys and analytics numbers are removed.

Independent evaluation, not affiliated with Archestra.

Archestra field notes

The task: install Archestra and set up two teams, SEO and Content Editor. The SEO team has access to Google Analytics and has to build an app that monitors the site's search positions, then tell the Content Editor team which pages to fix. Below are the strengths and issues we found along the way, each with a short observation and, where we have one, a contribution idea.

Overall, the experiment was a success. The admin set up both teams, connected a new MCP server, and assigned permissions without trouble. The app was built and published. We didn't expect much from apps in cross-team work, since that feature is still in beta.

Archestra 1.4.0-rc.27 Quickstart · Docker Desktop · Windows 11 Embedded KinD cluster

Method

One tester drove the UI; Claude Code kept the log, ran checks in the terminal, and wrote each observation as a testable hypothesis with status, severity, steps, expected and actual result. Items marked "reported by the tester" were observed in the UI and not independently re-checked.

Everything ran locally on a developer laptop with the quickstart image. Only test accounts and test credentials were used. Site names, accounts, keys and analytics numbers are removed from this page.

Machine-readable version: findings.json.
